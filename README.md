🧊 CZII - CryoET Object Identification
This repository focuses on automated object identification in Cryo-Electron Tomography (CryoET) data using advanced image processing
and deep learning techniques. CryoET enables high-resolution 3D visualization of biological macromolecules in their native state, and 
this project aims to enhance object segmentation, classification, and structural analysis within CryoET datasets.
